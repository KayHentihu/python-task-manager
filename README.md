# 📚 Python Task Manager

Simple Task Manager berbasis Python yang dibuat sebagai project belajar bersama.

Project ini dikembangkan oleh tim yang terdiri dari 3 orang untuk belajar dasar Python, Git, GitHub, dan workflow pengembangan software secara kolaboratif.

## 🎯 Tujuan Project

Project ini dibuat untuk:

- Belajar membuat project Python sederhana
- Mempraktikkan penggunaan Git dan GitHub
- Belajar bekerja dalam tim
- Memahami branch, commit, dan Pull Request
- Belajar melakukan code review
- Menerapkan konsep dasar pemrograman Python

## ✨ Fitur

## 🚀 Cara Menjalankan

Pastikan Python sudah terinstall.

Clone repository:

    git clone https://github.com/KayHentihu/python-task-manager.git

Masuk ke folder project:

    cd python-task-manager

Jalankan program:

    python main.py

## 🌱 Git Workflow

Kami menggunakan workflow sederhana:

    main
     │
     ├── feature/...
     │
     └── feature/...
           ↓
         Commit
           ↓
          Push
           ↓
      Pull Request
           ↓
       Code Review
           ↓
         Merge
           ↓
          main

### Branch Naming

Gunakan format:

    feature/nama-fitur

Contoh:

    feature/add-task
    feature/delete-task
    feature/view-task

### Commit Message

Gunakan commit message yang jelas.

Contoh:

    Add task manager menu
    Add function to create task
    Fix task deletion
    Update README
